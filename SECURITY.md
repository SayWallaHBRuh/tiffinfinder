# Security

Tiffin Finder is a static site with no accounts, no payments and no server
of its own (it's hosted on GitHub Pages). If you find a security problem —
for example, a way to inject content into a page, a broken link that leaks
private data, or a way to make the site behave unsafely — please report it
privately instead of opening a public issue.

**Email:** sitesbyadeel@gmail.com

Please include:

- What you found and where (page, URL or file).
- Steps to reproduce it, if you can.
- Anything else that would help us understand the impact.

We'll read every report and respond as soon as we can. Please give us a
reasonable amount of time to fix a problem before sharing it publicly.

This isn't a paid bug bounty program.
